# 승인 시안 반영 — 2026-09-09

## 기준

- 크림색 비대칭 물방울, 짙은 헤드폰과 이중 헤드밴드가 캐릭터의 기준이다.
- 시스템 헤드폰 아이콘과 타원으로 캐릭터를 대체하지 않는다.
- 본문은 시스템 한글 폰트, 기본 좌우 여백 24pt, 주요 버튼 높이 56–58pt.
- 아이보리 바탕 / 연두색 CTA / 살구색 재생 버튼. 큰 글씨와 실제 콘텐츠 길이에 따라 화면은 스크롤된다.
- 공통 브랜드 그림과 도시별 그림을 분리한다. 실제 지도는 MapKit이며 그림으로 대체하지 않는다.
- 시안의 가상 서울 코스·여행 기록·다운로드 용량을 실제 데이터처럼 추가하지 않는다.

## 에셋

캐릭터 이동은 기존 위치 속도 조건 및 Reduce Motion을 존중하는 작은 흔들림이며, 관절별 걷기 애니메이션은 아니다.

## 실제 화면 검수

1. 홈: 히어로 캐릭터가 잘리지 않는지, 추천 여행 제목과 버튼이 읽히는지.
2. 둘러보기: 준비 중인 도시를 실제 제공 코스로 오인하지 않는지.
3. 코스 상세: 긴 제목과 이야기 순서가 큰 글씨에서도 잘리지 않는지.
4. 여행 준비: 캐릭터 투명 경계, 비활성 버튼, 실제 준비 상태.
5. 여행 지도: 실제 MapKit 지도 위 작은 캐릭터, 다음 장소와 하단 패널.
6. 플레이어·장소 이야기: 그림 크롭, 버튼 터치 범위, 접근성 라벨.
7. 여행 완료·내 여행: 투명 캐릭터/가방, 실제 기록만 표시, 날짜.

정적 시안에 있던 검색·저장 탭은 아직 구현되지 않은 기능이므로 작동하지 않는 장식 버튼으로 추가하지 않았다.
후속 책임 경계 리팩터링에서 52분 고정값을 제거했다. 완료 기록과 날짜는 엔진이 만든 실제 세션 기록에서 표시한다.
GitHub 반영 후 Actions build/test가 성공한 커밋만 내부 TestFlight 배포 대상으로 사용한다. 배포 결과는 해당 CI 실행에서 확인한다.
